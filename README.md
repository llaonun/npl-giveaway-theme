# NPL Giveaway

A custom WordPress theme for the NPL Season 3 giveaway by LekhaSetu. Predict match winners, earn points, win Rs. 1,000. Works with the NPL Giveaway plugin (signup, predictions, leaderboard).

- **Version:** 2.0.2
- **Author:** Nirmal Kumar Bhattarai
- **License:** MIT

## Install

1. Download or clone this repository.
2. Copy the folder into `wp-content/themes/` on your WordPress site.
3. Activate it in WordPress admin (Appearance > Themes).
